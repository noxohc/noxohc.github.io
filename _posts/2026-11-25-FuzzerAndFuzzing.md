## 1. Fuzzing이란?

Fuzzing(퍼징)은 프로그램에 다양한 입력값을 자동으로 전달하여 오류나 보안 취약점을 발견하는 테스트 기법이다. 이를 수행하는 도구를 Fuzzer(퍼저)라고 한다.

예를 들어 문자열을 입력받는 프로그램에 매우 긴 문자열, 특수문자, 비정상적인 데이터를 반복적으로 입력하여 프로그램 충돌이나 메모리 오류 등을 발견할 수 있다.

### 동작 과정

1. 테스트할 입력값을 생성하거나 변형한다.
2. 생성된 입력값을 프로그램에 전달한다.
3. 프로그램의 충돌이나 비정상적인 동작을 확인한다.
4. 오류가 발생한 입력값을 저장하고 테스트를 반복한다.

## 2. Fuzzing의 종류

### 2.1. 내부 정보 활용에 따른 분류

| 종류        | 특징                                |
| --------- | --------------------------------- |
| Black-box | 프로그램 내부 구조를 알지 못한 상태에서 입력과 결과만 확인 |
| Grey-box  | 코드 커버리지 등 일부 실행 정보를 활용            |
| White-box | 프로그램 내부 구조와 코드를 분석하여 입력값 생성       |

코드 커버리지(Code Coverage)란 테스트 과정에서 프로그램의 어느 부분이 실행되었는지를 나타내는 정보이다. 이를 활용하면 아직 실행되지 않은 코드 영역을 효율적으로 탐색할 수 있다.

### 2.2. 입력값 생성 방식에 따른 분류

- **Mutation-based Fuzzing:** 기존 입력값의 일부를 변경하여 새로운 데이터를 생성하는 방식이다. 예를 들어 `abcd`를 `abXd`, `abcdd` 등으로 변형한다.
- **Generation-based Fuzzing:** 파일 형식이나 프로토콜 등 정해진 규칙을 기반으로 새로운 입력값을 생성하는 방식이다.

## 3. 대표적인 Fuzzer

### 3.1. AFL++

코드 커버리지를 기반으로 기존 입력값을 변형하면서 새로운 실행 경로를 탐색하는 퍼저이다. QEMU 등의 모드를 활용하면 소스 코드가 없는 바이너리도 테스트할 수 있다.

### 3.2. libFuzzer

LLVM에서 제공하는 커버리지 기반 퍼징 엔진이다. 테스트 대상과 동일한 프로세스에서 특정 함수를 반복적으로 실행하며, C/C++ 라이브러리 테스트에 적합하다.

### 3.3. Honggfuzz

보안 취약점 탐지를 위한 퍼징 도구이다. 소프트웨어 기반 커버리지뿐만 아니라 지원되는 환경에서는 하드웨어 기반 실행 정보도 활용할 수 있다는 특징이 있다.

### 3.4. OSS-Fuzz

Google에서 운영하는 오픈소스 대상 지속적 퍼징 서비스이다. 단일 퍼저가 아닌 여러 퍼징 엔진을 활용하여 프로그램을 지속적으로 테스트하고 오류를 발견한다.

## 4. 주요 도구 비교

| 도구        | 주요 특징                  | 활용 대상       |
| --------- | ---------------------- | ----------- |
| AFL++     | 실행 경로 기반 입력 변형         | 프로그램 및 바이너리 |
| libFuzzer | 프로세스 내부 반복 실행          | 함수 및 라이브러리  |
| Honggfuzz | 하드웨어·소프트웨어 기반 실행 정보 활용 | 프로그램 보안 테스트 |
| OSS-Fuzz  | 지속적인 자동 퍼징             | 오픈소스 프로젝트   |

각 도구는 실행 방식과 활용 대상에 차이가 있으므로 테스트하려는 프로그램의 특성에 맞게 선택해야 한다.

## 5. 장점과 한계

퍼징은 사람이 예상하기 어려운 입력값을 자동으로 테스트하여 잠재적인 보안 취약점을 발견할 수 있다는 장점이 있다.

그러나 모든 실행 경로를 탐색할 수 있는 것은 아니며, 발견된 오류가 실제로 악용 가능한 취약점인지 판단하려면 추가적인 분석이 필요하다.

## 6. 느낀 점

이번 미션을 통해 퍼징이 단순히 무작위 데이터를 입력하는 것뿐만 아니라 프로그램의 실행 정보를 활용하여 효율적으로 취약점을 탐색할 수 있는 기법이라는 것을 알게 되었다. 이후에는 실제 퍼저를 사용하여 오류를 발견하고 분석하는 과정도 경험해 보고 싶다.
